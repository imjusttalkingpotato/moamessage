모아메시지

PC 설치·연결 방법

PC와 연결하면 휴대폰에서 모은 알림을 PC에서도 확인하고 분류할 수 있습니다. PC 연결은 선택 사항이며 휴대폰만 사용할 수도 있습니다.

Mac용 PC 프로그램 다운로드

0.1.54 · Apple Silicon Mac · macOS 13 이상 · ZIP 약 37 MB

PC 설치·실행 휴대폰 연결 연결이 안 될 때 삭제 방법

1. 프로그램 폴더 준비·실행

  1. 위의 다운로드 버튼으로 받은 moa-message-pc-macos-0.1.54.zip을 펼칩니다.
  2. 압축에서 나온 모아메시지-PC 폴더 전체를 원하는 위치로 옮깁니다. 시작 파일만 따로 옮기지 마세요.
  3. 기존 모아메시지 프로그램이 실행 중이라면 해당 터미널에서 Control(⌃)+C를 눌러 먼저 종료합니다.
  4. 폴더 안의 모아메시지_시작.command를 더블클릭합니다.
  5. PC 프로그램이 준비되면 브라우저에서 PC 알림함이 열립니다. 사용하는 동안 실행된 터미널 창을 유지합니다.

PC에서 알림을 받으려면 PC 프로그램이 실행 중이어야 합니다. 종료하려면 해당 터미널에서 Control(⌃)+C를 누릅니다. 브라우저 창만 닫으면 PC 프로그램은 계속 실행됩니다.

프로그램 폴더를 옮겨도 저장된 메시지·모델은 유지됩니다. 기존에 연결했다면 PC의 기기 연결 → 기존 연결 파일 열기에서 같은 파일을 여세요.

모아메시지가 이미 실행 중이면 기존 서버의 알림함을 엽니다. 다른 프로그램이 같은 포트를 사용한다는 안내가 나오면 그 프로그램을 확인한 뒤 다시 실행하세요.

2. 휴대폰과 연결

  1. PC와 휴대폰을 같은 Wi-Fi에 연결합니다. 휴대폰의 모바일 핫스팟을 켜고 PC를 그 핫스팟에 연결해도 됩니다.
  2. PC 알림함 위의 기기 연결을 엽니다. 현재 PC 주소를 선택하고 연결 파일 만들기 → 연결 파일 저장을 누릅니다.
  3. 저장한 moa-message-connection.json 파일을 USB 등 안전한 방법으로 휴대폰에 옮깁니다.
  4. 휴대폰의 모아메시지 설정 → PC 연결 파일 가져오기에서 옮긴 파일을 선택합니다.
  5. 휴대폰에서 지금 동기화를 누릅니다. 수집된 알림이 PC 알림함에 나타나는지 확인합니다.

연결 파일에는 알림을 열 수 있는 비밀 키가 있습니다. 채팅방이나 공개 저장소에 공유하지 말고 안전하게 보관하세요. PC 알림함을 잠그거나 다시 열었을 때는 기기 연결 → 기존 연결 파일 열기에서 같은 파일을 선택합니다.

PC 알림함의 ‘확인’ 표시는 카카오톡 등 원래 앱의 읽음 상태와 별개입니다.

3. 연결이 안 될 때

  • PC 프로그램이 실행 중인지, 두 기기가 같은 Wi-Fi나 휴대폰 핫스팟에 연결되어 있는지 확인합니다. 게스트 Wi-Fi나 기기 간 통신을 차단하는 네트워크에서는 연결되지 않을 수 있습니다.
  • PC 주소가 여러 개라면 PC의 Wi-Fi 설정에 표시된 IP 주소와 같은 항목을 선택합니다. 휴대폰의 핫스팟 주소를 선택하는 것이 아닙니다.
  • PC 방화벽이 프로그램의 4311 포트 연결을 허용하는지 확인합니다.

Wi-Fi·핫스팟을 바꿨거나 PC 주소가 바뀐 경우

  1. PC의 기기 연결 → 기존 연결 파일 열기에서 보관한 파일을 엽니다.
  2. 현재 PC 주소를 선택하고 선택한 PC 주소로 갱신 → 연결 파일 저장을 누릅니다.
  3. 갱신한 파일을 휴대폰으로 옮겨 PC 연결 파일 가져오기로 다시 선택한 뒤 지금 동기화를 누릅니다.

휴대폰에서 PC 주소를 직접 수정하는 방법

이미 연결한 같은 PC의 주소만 바뀐 경우에는 연결 파일을 다시 가져오지 않고 주소만 직접 수정해도 됩니다.

  1. PC의 기기 연결에서 현재 PC 주소를 확인합니다.
  2. 휴대폰의 모아메시지 설정 → PC 연결 주소 수정에 현재 PC 주소를 입력하고 저장합니다.
  3. 저장하면 동기화를 자동 요청합니다. 필요하면 휴대폰에서 지금 동기화를 누릅니다.

주소 변경에는 새 연결 파일을 만들지 않습니다. 기존 파일을 갱신하거나 휴대폰에서 주소만 수정하면 같은 비밀 키와 알림을 유지합니다. 처음 연결할 때는 PC 연결 파일을 가져와야 합니다.

AI 사용은 선택 사항

AI 모델 없이도 규칙으로 알림을 분류합니다. AI를 사용하려면 휴대폰에서 모델을 가져오거나 프로그램 폴더의 모아메시지_AI_설치.command를 실행해 PC 모델을 준비한 뒤, 휴대폰 설정에서 사용할 AI와 우선 기기를 선택합니다.

PC 모델은 자동으로 설치되지 않습니다. 처음 설치할 때 인터넷 연결이 필요하며, 모델 약 2.5 GB와 실행 파일·임시 파일을 위한 추가 저장 공간을 준비하세요.

PC AI를 사용하려면 PC 알림함을 열고 잠금을 해제해 두어야 합니다. 연결 파일 가져오기와 AI 모델 설치는 각각 별도 절차입니다.

4. 프로그램·AI·저장 정보 삭제

프로그램 폴더, PC AI, PC 저장 정보는 서로 다른 위치에 있습니다. 프로그램 폴더만 삭제해도 AI 모델과 저장된 알림은 남습니다.

삭제할 항목 선택

먼저 실행 중인 모아메시지와 AI 설치 프로그램의 터미널에서 각각 Control(⌃)+C를 누르고 종료될 때까지 기다립니다. PC 알림함을 열어 둔 브라우저 탭도 닫습니다.

삭제 대상휴지통으로 옮길 항목유지되는 내용
프로그램만압축 해제한 모아메시지-PC 폴더설치한 PC AI와 PC 저장 정보
PC AI만~/Library/Application Support/모아메시지/runtime 폴더프로그램과 PC 저장 정보
PC 저장 파일만~/Library/Application Support/모아메시지/relay 폴더프로그램과 설치한 PC AI

Finder에서 Shift + Command + G(⇧⌘G)를 누르고 ~/Library/Application Support/모아메시지를 입력하면 runtime과 relay 폴더를 찾을 수 있습니다. runtime에는 모아메시지가 설치한 AI 실행기와 모델, relay에는 PC에 보관한 알림과 연결 정보가 들어 있습니다. 실행하거나 AI를 설치한 적이 없다면 해당 폴더가 없을 수 있습니다.

PC AI만 삭제했다면 휴대폰 설정의 PC AI 사용을 끄세요. relay를 삭제하면 기존 연결 정보가 없어지므로, 다시 연결할 때는 새 PC 연결 파일을 만들어 휴대폰에 가져와야 합니다.

relay만 삭제해도 브라우저 보관 정보와 직접 저장한 연결 파일은 남습니다. 이 정보도 삭제하려면 아래 전체 삭제 절차의 5~6번을 함께 진행하세요.

프로그램·AI·PC 저장 정보를 모두 삭제

  1. 연결한 각 휴대폰의 모아메시지 설정 → 이 휴대폰 연결 해제를 누릅니다. 휴대폰에 모아 둔 메시지는 유지됩니다.
  2. 실행 중인 모아메시지와 AI 설치 프로그램의 터미널에서 각각 Control(⌃)+C를 누르고 종료될 때까지 기다립니다. PC 알림함을 열어 둔 브라우저 탭도 닫습니다.
  3. 압축 해제한 모아메시지-PC 폴더를 휴지통으로 옮깁니다. 내려받은 ZIP과 프로그램 폴더의 복사본도 더 이상 필요 없다면 함께 정리합니다.
  4. Finder에서 Shift + Command + G(⇧⌘G)를 누르고 ~/Library/Application Support/를 입력합니다. 그 안의 모아메시지 폴더 전체를 휴지통으로 옮깁니다. 설치한 PC AI와 PC에 저장된 알림·연결 정보가 함께 삭제됩니다.
  5. 직접 저장했던 moa-message-connection.json과 복사본을 저장한 위치에서 찾아 휴지통으로 옮깁니다. 휴대폰·외장 저장장치 등에도 복사했다면 해당 기기에서 따로 정리합니다.
  6. PC 알림함을 사용한 각 브라우저의 사이트 데이터 관리에서 PC 알림함 주소(기본 http://127.0.0.1:4310)의 데이터를 삭제합니다. 브라우저에도 암호화된 알림과 전달 대기 기록이 별도로 남을 수 있습니다. 브라우저가 127.0.0.1 전체를 묶어 삭제한다면 같은 주소를 쓰는 다른 로컬 프로그램의 데이터에도 영향을 줄 수 있으므로 대상을 확인하세요.
  7. 삭제 대상을 확인한 뒤 휴지통을 비우면 일반적인 복원 기능으로 되돌릴 수 없습니다.

이 절차는 PC의 모아메시지 파일을 정리하는 방법입니다. 휴대폰 앱에 저장된 메시지·AI 모델과 카카오톡·Gmail 등 원래 앱의 대화는 삭제하지 않습니다. 별도로 설치해 다른 용도로 사용하는 Ollama도 삭제 대상에 포함하지 않습니다.

PC 알림함의 ‘연결된 알림 보관함 비우기’는 PC만 삭제하는 기능이 아닙니다. 이 버튼을 누르면 연결된 휴대폰의 알림에도 다음 동기화 때 삭제가 반영됩니다. 휴대폰의 메시지를 유지하면서 PC만 정리하려면 위의 파일 삭제 절차를 사용하세요.
